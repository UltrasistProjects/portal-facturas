Ver evidencias "listado-estatus" y "seguimiento-rechazo".

Observaciones del ejecutor (revisión de evidencias)

  • Las páginas de error se muestran como si el usuario no tuviera sesión. Con sesión iniciada, las respuestas 404 y 409 del portal muestran la variante para usuario anónimo: sin menú lateral y con el botón «Ir al acceso» (lleva a /login) en lugar de «Volver al inicio». Causa: render_error (app/main.py) no pasa el usuario al contexto de error.html, y base.html usa entonces el bloque anónimo. No afecta los criterios de las HUs. Evidencias: evidencias/HU-04/06-envio-bloqueado-por-obligatorio.png, evidencias/HU-17/09-factura-ajena-404.png.

Ninguna de estas observaciones incumple un criterio de aceptación de las HUs, por eso no cambian su resultado; se documentan para su corrección.

Problemas durante la ejecución

  • scripts/reset_demo.py deja la base vacía cuando las cuentas demo ya existen en Keycloak. Al intentar restablecer la demo para la corrida final, el script respaldó y recreó el esquema, y luego el seed falló: Keycloak respondió HTTP 400 «invalidPasswordHistoryMessage» al reasignar la misma DEMO_PASSWORD a las cuentas demo (política passwordHistory(1) del realm). El script informó «Keycloak no respondio (reset_password: http_400)… la base no se modifico», pero la base quedó migrada y vacía (0 usuarios). Se reprodujo la respuesta 400 directamente contra la API de administración de Keycloak. Acción: Se restauró el respaldo automático que el propio script generó (scripts/restore_backup.py backups/20261002-000701 --yes). No se borraron volúmenes ni cuentas de Keycloak. Es un defecto de las herramientas de operación, no de una HU.
  • Ajustes de la propia suite durante la depuración. En las corridas de depuración se corrigieron errores de la suite, no del portal: el nombre accesible del enlace «Facturas» incluye el glifo del ícono; las capturas tras desplazamientos se tomaban a mitad de la animación (scroll-behavior: smooth de Bootstrap); y algunas capturas no mostraban la fila o el estatus verificado. Las evidencias de este documento son de la corrida final completa, ejecutada con la suite ya corregida.
